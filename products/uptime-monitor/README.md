# Free uptime + SSL monitor

1. Use this folder as its own GitHub repository (it can be private).
2. List your sites in `sites.txt`.
3. It checks every 15 minutes. If a site is down, or its SSL certificate expires within 14 days, it opens a GitHub issue and GitHub emails you.

No server to run and no monthly fee. Scheduled GitHub Actions can be delayed by a few minutes at busy times.
